# 一箭又一箭

福州大学 2026 秋季《软件工程》第二次个人作业。一个使用 Python 标准库 Tkinter 从零实现的箭头益智小游戏。

## 运行

准备好 Python 3 后，在项目根目录执行：

    python3 main.py

程序不需要安装第三方库。

## 游戏规则

- 点击棋盘中的一个箭头。
- 如果它前方直到边界都没有其他箭头，箭头会飞出棋盘。
- 如果前方有其他箭头挡住，会提示碰撞并扣除一次机会。
- 清除全部箭头即可进入下一关；机会用完时可重新开始本关。

## 项目结构

- main.py：Tkinter 界面、开始页、游戏页和结果页。
- game_rules.py：箭头数据、路径扫描与三关关卡数据。
- tests/test_game_rules.py：规则层的单元测试。

## 测试

在项目根目录执行：

    python3 -m unittest discover -s tests -v

测试覆盖空格点击、可离开箭头、被阻挡箭头，以及三个关卡的通关顺序。
